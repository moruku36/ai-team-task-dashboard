# 担当者・表示グループの未設定対応（運用メモ）

## 仕様
- 担当者の未設定は空文字 `''`、表示グループの未設定は `null` だけです。実在しない担当者や分類は割り当てません。
- `null`・空白だけの担当者・未知の分類名・項目の省略は、従来どおり拒否します。
- 画面には「未分類」タブが加わります。件数は全カードを一度ずつ数え、検索・編集・再読込でも消えません。担当者が空のカードは「主担当: 未設定」と表示します。
- 変換器（`cloud/import-snapshot.mjs`）は、担当者・表示ラベルがなければ `''` と `null` にします。型が不正な値や、表示ラベルが複数ある場合は従来どおりエラーです。

## 運用上の注意
1. **旧版へ戻すと全体 503 になります。** 未分類（担当者空・グループ null）のカードを保存した後に、この対応より前のコードへ戻すと、`GET /api/tasks` が全体で 503 になります（データは壊れません）。復旧するときは、旧版へ戻さず、この対応を含む版のコードをデプロイし直してください。ロールバックが必要なときも、この対応を含む版だけを使ってください。
2. **変換器の `records` は、呼び出し側が非公開で保存してください。** `convertBacklogFiles` は、元の `updated_date`・`created_date`・日時の根拠・未設定フラグを `records` として返しますが、保存はしません。記録はリポジトリの外（非公開の場所）に置き、GitHub へは送らないでください。`updatedAtBasis` が `created_date` のカードは、元の更新日時が不明です。
3. API で書き込んだカードの更新日時は書き込み時刻です。元の更新日時とは別のものとして扱ってください。
