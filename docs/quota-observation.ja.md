# 残量の表示と観測日時

タスク一覧の同期時刻と、各利用枠の残量を観測した日時は別です。画面は30秒ごとに保存済みデータを再取得します。この再取得だけでは、サービスからの残量採取や古い観測日時の更新は行いません。

- Codex: 本人契約の週間枠と5時間枠。使用率から `100 - usedPercent` で残量を求めます。枠は取得元の期間で判定し、primary/secondaryの位置で決めません。
- Claude: 本人契約の週間枠と5時間枠。取得失敗時は、過去の成功値と観測日時を参考値として表示します。
- Antigravity: Gemini共有枠とClaude/GPT共有枠。モデルごとの独立残量ではありません。観測日時が提供されないCLI値は、収集日時と明記します。
- ChatGPT: 単独の利用枠は取得していません。AntigravityのGPT表記をChatGPT契約の利用枠として扱いません。

未提供の枠は `?`、古い値は `reference` と表示します。表示更新・リセット到来だけで現在値へ昇格させません。参考値の割合・リセット日時・観測日時は同じ保存済み行を使います。
