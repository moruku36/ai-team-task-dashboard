# Windows合成試験記録（2026-10-11）

公式Backlog.md v1.53.0、Windows x64 standalone、Node v22.23.2、PowerShell 5.1で実施。既存Claude CLIが初版を実装し、Codex側で保存先保護・MCP/同task競合試験を追加して最終レビューしました。新規LLM API課金なし。

`node tests/integration.mjs --exe <検証済みbinary>`：**32/32合格**。一時no-git rootの合成30件のみを使用し、試験終了後のserver/MCPプロセス停止と一時root削除を確認しました。GUI操作・実ブラウザ描画は試験していません。画面と同じHTTPデータおよびWS通知を検証しています。

同taskへの並列追記は5/5が受理され、全追記の保持を確認しました。別taskの5件並列更新でも30件の保持を確認しました。古いstatusの再送は受理されました。したがって古い状態の拒否・主担当の強制を保証するものではありません。再接続はWS clientの切断・再接続、再起動はserver process再起動です。Windows OSのsleep/logout/reboot試験とは区別します。

server listenerは127.0.0.1のみで、同じPCの非loopback IPv4アドレスへの接続が拒否されました。firewall/VPN/認証設定の変更なし。公式stdio MCPのhandshake・task_editからWS/HTTP反映まで確認し、永続MCP登録なし。
