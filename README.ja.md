## 撤回済みの初版案（参考）

**推奨：まず Kanboard（MIT）を Windows ローカルで使う。** 標準の看板、短い説明テンプレート、証跡リンクで始め、更新は本人または指定した1人に集約する。初版に独自アプリやAI自動実行機能は作らない。

- 現在：**設計のみ**。アプリ実装、インストール、外部公開、認証連携は未実施。
- 初期構成：Windows上の既存WSL2を優先し、Apache + PHP + SQLite。利用先は localhost のみ。既存IIS/PHPがある場合は再利用を検討。
- 外出先：保守最小なら同じKanboardを常時稼働ホストへ移す。追加月額0円を優先する場合は、認証付きの読み取り専用クラウド・スナップショットを次段階で検討。
- VercelにKanboard/PHPサーバーや永続SQLiteをそのまま載せる計画ではない。無料枠は用途・上限・休止条件付き。
- 承認待ちは表示するだけ。カードの移動・チェック・コメントで、購入、公開、認証設定などの実行権限は生まれない。
